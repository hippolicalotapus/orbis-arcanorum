# Orbis Arcanorum

**The World of Mysteries** — a worldwide discovery community for independent occult merchants, collectors, paranormal investigators and historical archives.

## Current status
Private development repository. The website is not yet deployed. The initial static prototype exists separately and has not yet been committed here. Listings in that prototype are fictional demonstrations; no live vendor accounts, public registrations, auctions or payments are operational.

## Planned MVP
- Vendor-controlled independent storefronts linking to existing websites
- Searchable worldwide directory by country and specialty
- Akashic Archives with cited historical sources and provenance records
- Collector profiles, moderation and privacy safeguards

## Hosting
Target: Netlify free tier. Keep the frontend static/portable and connect a secured backend for persistent data and authentication before public launch.

## Commerce
No platform-owned inventory. Payments, trades and auctions remain future milestones requiring security and legal/payment-provider review.
